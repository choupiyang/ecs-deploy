是什么

SenseNova-Vision 是商汤科技（日日新）提出的统一多模态视觉生成模型。它的核心思想是：把计算机视觉的所有任务都表达为统一多模态模型（UMM）的文本和图像生成，而不是为检测、分割、深度估计等每个任务分别设计专用的预测头和解码器。

简单说：过去做视觉任务需要一堆专用模型拼在一起，SenseNova-Vision 用一个模型搞定目标检测、语义分割、深度估计、法线估计、OCR、关键点、多视图三维重建、相机位姿估计——而且全部通过自然语言指令控制。

核心架构：Mixture-of-Transformers (MoT)

SenseNova-Vision-7B-MoT 基于 MoT 架构，7B 参数规模。它将不同视觉任务统一到三种输出格式：

📝 结构化文本 目标检测、引用定位、OCR、GUI定位、关键点、相机参数→输出归一化坐标+结构化字段
🖼️ 密集图像 深度图、法线图、点云图、二值掩码→输出像素对齐的目标图像
📄 图文混合 多实例分割、对话式分割→文本标签+生成的掩码或视觉图

关键贡献

  • 统一范式：将异构视觉任务统一到 UMM 的输入输出空间，不需要任何任务专用预测头
  • SenseNova-Vision Corpus：构建了 5000 万样本的大规模视觉指令微调数据集，覆盖文本、图像、图文混合三种目标类型
  • 全任务覆盖：同一个模型同时覆盖结构化视觉理解、密集几何预测、分割、多视图几何，且支持语言定义的任务变体
  • 无需专用分支：无检测头、无分割解码器、无深度预测分支——全靠统一生成

与通才视觉模型对比

与 Youtu-VL、Vision Banana 等同类通用视觉模型对比，SenseNova-Vision 在检测（COCO 53.7 vs 47.1）、语义分割（Cityscapes 71.2 vs 69.9/70.4）、深度估计（NYUv2 δ1 98.1 vs 90.4/94.8）上全线领先。

快速上手

git clone https://github.com/OpenSenseNova/SenseNova-Vision.git
cd SenseNova-Vision
bash setup.sh sensenova-vision
conda activate sensenova-vision

# 运行示例
bash scripts/run_sensenova_vision.sh example

# 单次推理（例如人像二值分割）
bash scripts/run_sensenova_vision.sh inference \
  binary_seg "person" examples/images/2.jpg

# 启动 Web Demo
MODEL_PATH=/path/to/SenseNova-Vision-7B-MoT \
  bash scripts/run_sensenova_vision.sh demo

训练数据：SenseNova-Vision Corpus

5000 万样本，覆盖四大任务家族：

  • 结构化视觉理解（检测、指代定位、关键点、OCR、GUI）
  • 密集几何预测（深度、法线）
  • 分割（指代、推理、交互、通用、对话式）
  • 多视图几何（点云重建、相机位姿）

⚠️ 局限性

  • 不是每个任务的专用最优模型
  • 文本输出需要任务专用解析器
  • 深度/法线/点云/位姿预测需谨慎验证后再下游使用
  • 对提示词措辞和输出格式敏感
